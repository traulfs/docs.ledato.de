# Halterungen & Montage

Befestigungslösungen für die Installation der LED-Panels.

## Optionen

- **Saugnäpfe** — für Montage an Glasflächen (z. B. Schaufenster)
- **Rahmenlösungen** — für feste Installation an Fassaden
