# LED-Panels

Übersicht über die Ledato LED-Panel-Hardware: Formate, Pixelabstände und modulare Erweiterbarkeit.

## Produktfamilie

- **P2** — feinerer Pixelabstand, für kurze Betrachtungsabstände (z. B. Schaufenster)
- **P10** — größerer Pixelabstand, für Fassaden und größere Betrachtungsabstände
