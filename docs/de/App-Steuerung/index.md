# App-Steuerung

Inhalte werden direkt vom Smartphone gesteuert, gestaltet und aktualisiert.

## Funktionen

- Bilder, GIFs und Animationen austauschen
- Ferngesteuerte Inhaltsaktualisierung
- Intuitive Bedienung ohne technisches Vorwissen
